Konfigurasi Merchant QRIS

Ambil string QRIS statis dari aplikasi m-Banking Anda (BCA, ShopeePay, Nobu, dll) atau gunakan QR code scanner untuk mengekstrak stringnya.

Endpoint ini akan otomatis di-POST ketika mutasi pembayaran lunas terverifikasi.

Panduan Integrasi REST API

1. Buat Invoice dari Website Anda: 
curl -X POST https://your-pi-ip:8088/api/invoices \
  -H "Content-Type: application/json" \
  -d '{"amount": 50000, "memo": "Order #123"}'
2. Webhook Mutasi Masuk dari HP / Bot (MacroDroid / Tasker): 
curl -X POST https://your-pi-ip:8088/api/mutations/webhook \
  -H "Content-Type: application/json" \
  -d '{"bank": "BCA", "amount": 50231, "type": "CR"}'
3. Callback Otomatis ke Toko Anda:

Engine ini akan mengirim payload JSON dengan header X-QRIS-Engine-Secret secara instan begitu nominal cocok.
